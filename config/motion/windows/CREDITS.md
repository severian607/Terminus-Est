# Window preset credits

Presets not listed here are original. The upstream animation files were taken from
LinuxBeginnings/Hyprland-Dots (formerly JaKooLit), which already ships them as Lua in
`config/hypr/animations/` and credits the original authors; curves and speeds are kept as the authors set them
(curve names are prefixed per preset so they cannot clash).
